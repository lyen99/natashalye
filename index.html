Paid-to-CRM Personalized Push Strategy

Designed and executed a cross-channel personalization initiative connecting paid acquisition data to CRM messaging — resulting in a 35% uplift in KYC conversions versus the control group.

// PROBLEM

Users acquired through paid ads on Google and Meta were receiving generic onboarding push notifications that didn't reflect the specific incentive or CTA they originally engaged with. This disconnect was contributing to low KYC completion rates among newly acquired users.

// SOLUTION

Built a personalized push notification system that dynamically matched CRM messaging to the specific paid ad creative that acquired each user. For example, users acquired via a "Welcome Bonus" ad received a push reinforcing that exact offer, while users from a "Recurring Buys" campaign saw messaging about zero-fee trading.

// TECHNICAL EXECUTION

Distilled user acquisition source data from the AppsFlyer integration and dynamically connected it with campaign creative data stored in Databricks. Mapped the enriched user segments to a table in Segment via Reverse ETL (RETL), then synced to Braze for targeted push notification delivery.

AI-Driven Web3 Daily News Digest

Designed and implemented an automated CRM content pipeline that delivers personalized daily crypto news summaries — powered by an internal news API and sentiment analysis.

// PROBLEM

Crypto markets move fast — users want to stay informed but are overwhelmed by noise. Generic news roundups lack relevance, and manually curating daily content doesn't scale across a global user base.

// SOLUTION

Leveraged an internal news API that scrapes RSS feeds and categorises articles using sentiment analysis to surface the most relevant stories. For each CRM push, pulled the top news stories associated with a target cryptocurrency, then delivered them as a "Your Daily Web3 Summary" in-app card — giving users a curated, timely reason to engage.

// TECHNICAL EXECUTION

The internal news API ingests articles from multiple RSS feeds and applies NLP-based sentiment classification to categorize stories by topic and sentiment. On the CRM side, built a dynamic content block in Braze that queries the API at send-time, pulling the top-ranked stories for the target coin and populating the push/in-app card with headlines, dates, and a trade CTA.
