Paid-to-CRM Personalized Push Strategy

Designed and executed a cross-channel personalization initiative connecting paid acquisition data to CRM messaging — resulting in a 35% uplift in KYC conversions versus the control group.

// PROBLEM

Users acquired through paid ads on Google and Meta were receiving generic onboarding push notifications that didn't reflect the specific incentive or CTA they originally engaged with. This disconnect was contributing to low KYC completion rates among newly acquired users.

// SOLUTION

Built a personalized push notification system that dynamically matched CRM messaging to the specific paid ad creative that acquired each user. For example, users acquired via a "Welcome Bonus" ad received a push reinforcing that exact offer, while users from a "Recurring Buys" campaign saw messaging about zero-fee trading.

// TECHNICAL EXECUTION

Distilled user acquisition source data from the AppsFlyer integration and dynamically connected it with campaign creative data stored in Databricks. Mapped the enriched user segments to a table in Segment via Reverse ETL (RETL), then synced to Braze for targeted push notification delivery.
